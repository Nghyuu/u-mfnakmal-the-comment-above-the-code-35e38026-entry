Entry for the [make.fun bounty "The Comment Above the Code"](https://make.fun/bounty/u-mfnakmal-the-comment-above-the-code-35e38026).

`main.ts` writes one line to `/output/entry.txt`: the comment a developer
left above fragile production code — funny because it is true.

Run it with `MAKEFUN_OUTPUT_DIR` set, e.g.:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
